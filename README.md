A Socratic, AI-driven cognitive trainer built on Google AI Studio that converts developer logic into syntax, builds muscle memory through scaffolding decay, and eliminates AI over-reliance
# Compiler Within 🧠⚡
> **A Cognition-First Pedagogical Framework for Code Construction & Algorithmic Synthesis**

## 📌 Problem Statement
Current coding platforms teach syntax or act as generative AI code-dumpers. Learners copy-paste solutions without internalizing underlying logic, leading to severe failure when converting ideas into runnable code independently.

## 💡 Solution
**Compiler Within** is an AI-driven cognitive trainer built on Google AI Studio that bridges the gap between abstract algorithmic logic and precise syntax execution through:
* **Socratic Cognitive Coaching**: Guides multi-step reasoning before code generation.
* **Progressive Syntax Fading**: Systematically decays syntax scaffolding over time to build muscle memory.
* **Error Psychology Debugging**: Fixes underlying mental models by asking targeted intent questions during runtime errors.

---

## 🚀 Prototype Setup (Google AI Studio)
1. Open [Google AI Studio](https://aistudio.google.com).
2. Set Model to `Gemini 2.5 Flash` and Temperature to `0.2`.
3. Paste the system instructions from `system_prompt.txt` into **System instructions**.
4. Test query: `I want to write a program that reverses an array in C++`.
